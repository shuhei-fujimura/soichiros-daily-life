# Apps Script setup

1. Google Apps Scriptで新しいプロジェクトを作る。
2. `Code.gs` の内容を貼り付ける。
3. `CONFIG.TOKEN` を長めの合言葉に変える。
4. デプロイから「ウェブアプリ」を選ぶ。
5. 実行するユーザーは「自分」、アクセスできるユーザーは運用に合わせて設定する。
6. 発行されたWebアプリURLをアプリの「親設定 > 動画保存設定」に入れる。
7. 同じ合言葉を「親設定 > 動画保存設定」に入れる。

動画を保存すると、Google Driveに日付別フォルダが作られ、スプレッドシートの `videos` シートに技名・日付・回数・Drive URLが記録されます。

アプリ側は動画送信後、`localId` を使って `videoStatus` を確認します。保存が完了していればDrive URLを受け取り、成長メモの「動画の記録」に `見る` リンクとして表示します。

`installNightlyTrigger` を一度実行すると、22時の定時トリガーが作られます。今は動作確認用の記録だけを残すプレースホルダーです。日別自動集計を本格化するときは、`daily_progress` シートへの送信仕様と合わせて拡張します。
